# Venture Signal To Action

## If Strong Customer Signal
Move to demo, product improvement, or monetization test

## If Strong Revenue Signal
Move to paid pilot, quote flow, or founder payment approval review

## If Strong Growth Signal
Double down on channel — improve landing funnel

## If Strong Product Usage Signal
Improve retention, save/share flow, onboarding

## If Strong QA Signal
Allow stage/customer/growth gating to proceed

## If Strong Investor Proof Signal
Improve investor packet or demo sequence

## If Weak Signal
Revise segment, offer, copy, CTA, or channel

## If No Signal
Retest with new segment or offer; park if 2nd wave fails

## If Contradictory Signal
Do not promote — reconcile evidence first

## If Stale Signal
Refresh validation before acting

## Best Signal-Triggered Next Action
Capture BUILD_SIGNAL in venture-telemetry.json — fix build before demand tests
