# Venture Visual System

**Last reviewed:** 2026-05-22

## Color System
- **Primary:** Emerald / jade
- **Secondary:** Deep forest
- **Accent:** Gold tick
- **Neutral:** Slate/zinc scale
- **Background:** Dark ledger gradient
- **Success / Warning / Danger:** Semantic tokens aligned to world

## Surface System
- **Cards:** Tinted borders, subtle shadow, no heavy glass
- **Panels:** Dense data panels
- **Navigation:** Sticky, translucent only if contrast OK
- **Forms:** Single-column on mobile

## Graphic System
- **Icons:** Lucide — consistent stroke
- **Charts:** Only if venture has data story
- **Diagrams:** Live risk/opportunity meter
- **Product visuals:** HeroGraphicPanel + DomainCommandGraphic

## Motion System
- Page: minimal entrance
- Hover: border/opacity
- Loading: skeleton, not spinners everywhere

## Component Style
- **Buttons:** Primary filled (accent), secondary outline
- **Cards:** 2xl radius, world border
- **Hero:** terminal

## Visual Consistency Rules
1. Use assigned worldId tokens only  
2. One accent hue  
3. Mobile-first spacing  
4. CTA above fold on 390px
