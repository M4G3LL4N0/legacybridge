# Venture Growth Experiment

## Experiment Name
Manual outreach — waitlist test

## Hypothesis
We believe manual outreach can bring operations leaders and technical founders to waitlist because Reduce risk on Start an automation run and review the output

## Channel
Manual outreach

## Audience
Operations leaders and technical founders

## Message
Reduce risk on Start an automation run and review the output log

## CTA
Join waitlist

## Strong Signal
Qualified signup, demo booked, reply with pain, quote with budget

## Weak Signal
Views/likes only, generic compliments

## No Signal
Zero replies/clicks after 7 days + 100 impressions

## Minimum Sample
7 days + 100 impressions

## Test Duration
30 days

## Data To Capture
Source, message variant, CTA clicks, form fills, reply quality

## Next Action If Strong Signal
Improve landing funnel conversion

## Next Action If Weak Signal
Revise message, landing page, or audience

## Next Action If No Signal
Stop channel after 30 days or 100 impressions with zero qualified signups/replies; try alternate channel: SEO
