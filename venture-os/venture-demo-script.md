# Venture Demo Script

## 30-Second Demo
"Legacybridge helps you system intelligence for legacy software. Click Demo, enter your use case, and you get a automation run log + recommended actions — prototype today."

## 2-Minute Demo
Problem → CTA → input → output → early access ask. (See venture-demo-path.md)

## 5-Minute Demo
Add roadmap, tech approach, design lane, and paid pilot offer (no fake traction).

## Demo Click Path
`/` → `/demo` → submit → confirmation/output

## Demo Talking Points
- Honest MVP labeling
- Specific wedge vs generic AI
- What proof event proves

## Demo Proof Points
Working build (local), visible output, founder follow-up

## Demo Weaknesses To Avoid
Fake metrics, enterprise claims, broken nav links on prod

## Best Demo Upgrade
Fix build, then implement core action: Start an automation run and review the output log
