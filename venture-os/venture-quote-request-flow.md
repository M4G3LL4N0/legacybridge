# Venture Quote Request Flow

## Should This Use Quote Requests?
optional fallback

## Quote CTA
Get a quote

## Quote Form Fields
Name, Email, Company, Role, Budget, Timeline, Problem, Desired outcome, Project details, Urgency, Notes

## Minimum Required Fields
Email, problem, desired outcome, budget range

## Confirmation Message
Thanks — we'll review and respond with a scoped proposal. No payment required yet.

## Follow-Up Action
Founder sends manual proposal within 3-5 business days

## Strong Buyer Signal
Budget range + timeline + specific workflow described

## Weak Buyer Signal
Email only, no budget

## Best Implementation
Simple form on /quote — static or form service with founder approval
