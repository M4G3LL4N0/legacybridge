# Venture MVP Proof

**Last reviewed:** 2026-05-22

## MVP Question
Will a target user take a proof action within 5 minutes of landing?

## Minimum Useful Product
Honest marketing site + one working proof path (demo, form, or output)

## Demo Path
Mission/demo route shows core capability with labeled prototype

## User Action
User completes demo path and submits request or saves an artifact

## Proof Event
User completes demo path and submits request or saves an artifact

## Fake Progress To Avoid
- Vanity dashboards
- Fake metrics
- Pricing page without value
- Multi-feature nav without routes

## Fastest MVP Upgrade
Fix build + one real demo interaction
