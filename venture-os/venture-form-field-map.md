# Venture Form Field Map

## Forms Needed
contact only

## Current Forms
None detected in components/

## Recommended Forms
Waitlist: email, use case, role (optional)
Demo request: email, name, company, use case, urgency
Quote request: email, company, use case, budget range, timeline
Feedback: problem, desired outcome, willingness to pay (optional)
Paid pilot request: email, use case, budget, timeline, decision maker
Contact: email, message

## Minimum Fields
Email: required
Name: optional until demo
Company: optional
Role: optional
Use case: required for high-intent
Pain: optional
Urgency: optional (timeline)
Budget: required for quote/revenue signal
Timeline: optional
Message: optional for contact

## Fields To Avoid For Now
Payment card · SSN · Health data · Full address · Sensitive financials

## Form Data Destination
Markdown log in venture-os

## Best Form Field Action
Document minimum fields — capture manually in venture-customer-signal-capture.md until form approved
