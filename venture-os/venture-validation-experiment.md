# Venture Validation Experiment

## Experiment Name
legacybridge-demo_test-20260524

## Hypothesis
We believe Operations leaders and technical founders has Teams cannot verify identity, claims, or risk fast enough for high-stakes decisi and will see a live demo when offered Demo.

## Validation Mode
DEMO_TEST

## Test Audience
Operations leaders and technical founders

## Test Surface
Homepage CTA + form on live site

## Test Action
User submits form, books demo, replies to outreach, or completes interview

## Strong Signal
Books demo, asks detailed workflow questions, requests follow-up or trial access

## Weak Signal
Generic signup, vague compliment, no use case, no reply to follow-up

## No Signal
Zero signups/replies after minimum sample; only bounce traffic

## Minimum Sample
5 qualified interactions or 20 waitlist signups with use-case field

## Test Duration
7 days initial; 30 days before park decision

## Data To Capture
Email, segment, pain quote, use case, urgency, objection, willingness to pay

## Next Action If Strong Signal
Build core workflow for: Start an automation run and review the output log

## Next Action If Weak Signal
Revise offer, CTA, or segment — do not add features yet

## Next Action If No Signal
Park or reposition segment; do not build new product surface
