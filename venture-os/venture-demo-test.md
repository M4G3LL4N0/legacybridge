# Venture Demo Test

## Can This Venture Be Demoed?
improve first — build must pass

## Demo Audience
Operations leaders and technical founders

## Demo Promise
Show that Start an automation run and review the output log produces visible value in one session

## Demo Flow
Step 1: State customer pain in their words
Step 2: Open live site / local demo
Step 3: Walk through Start an automation run and review the output log
Step 4: Show output or next step
Step 5: Ask validation questions

## What To Ask After Demo
"What would you pay to solve this?" "What did you expect that we missed?" "Who else has this pain?"

## Strong Signal
Asks for access, pilot, or intro; describes specific workflow

## Weak Signal
"Cool" with no follow-up questions

## Demo Risk
Broken build, fake data unlabeled, nav 404s on live site

## Fastest Demo Improvement
Fix build
