# Venture Homepage Composition

**Last reviewed:** 2026-05-22

## Current Homepage Structure
~13 sections; pattern: Hero plus dashboard mockup

## Recommended Homepage Structure
1. Hero with venture-specific visual  
2. Problem statement  
3. Product promise  
4. How it works  
5. Live risk/opportunity meter  
6. Use cases  
7. Proof / roadmap  
8. Early access  
9. Final CTA  

## Above-The-Fold Recommendation
- **Headline:** System intelligence for legacy software
- **Subheadline:** LegacyBridge transforms legacy systems into a system intelligence layer for safer change, clearer modernization sequencing, and pilot-led enterprise adoption.
- **Primary CTA:** Request early access / Book demo
- **Secondary CTA:** See how it works
- **Hero visual:** Live risk/opportunity meter
- **Trust line:** Founder-led MVP — honest labeling

## Section-by-Section Direction
| # | Purpose | Visual |
|---|---------|--------|
| 1 | Orient | Hero + world palette |
| 2 | Pain | Contrast typography |
| 3 | Promise | Single strong sentence |
| 4 | Mechanism | 3 steps max |
| 5 | Signature | Live risk/opportunity meter |
| 6 | Use cases | Cards, world borders |
| 7 | Proof | Roadmap or demo |
| 8 | Convert | CTA block |

## What To Combine
Merge redundant feature grids if more than two repeat the same message.

## What To Preserve
DistinctVentureHero, ProductHonestyNote, and venture-specific copy blocks.
