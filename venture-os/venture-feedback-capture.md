# Venture Feedback Capture

## Feedback Sources
Waitlist, demo, interview, form, email — manual only

## Feedback Fields
Customer segment, pain, use case, workaround, urgency, budget, outcome, objections, feature request, willingness to pay, referral, notes

## Storage Recommendation
Markdown log in venture-os/venture-customer-feedback-log.md (create on first signal)

## Feedback Scoring
Strong: specific pain + next step requested
Medium: interest but vague
Weak: polite only
Ignore: spam, irrelevant

## Follow-Up Rules
Follow up within 48h on strong/medium; one follow-up max on weak
